Easy mode lets you build a chart by filling out a short form instead of wiring nodes together. Pick what to measure, add filters and a breakdown, and pick a chart type. The preview updates while you work.

It works with every chart type and also supports charts with more than one series. See [Chart Types](/platform/chart-editor/chart-types) for what each one does.

![Chart editor in Easy mode, with the Series, Filters and Breakdown panel on the left and the live preview on the right](/images/chart-editor/easy-mode/overview.png)

### Switching modes

- **Easy to Canvas:** always possible. The chart carries over as nodes, so you can keep refining it on the canvas.
- **Canvas to Easy:** possible as long as Easy mode can show the chart. If the pipeline uses something the form can't represent, the **Easy** option is disabled and the editor tells you why, for example "Easy mode can't open this chart: a step combines several inputs."

![Easy option disabled with the message "Easy mode can't open this chart: a step combines several inputs."](/images/chart-editor/easy-mode/easy-unavailable.png)

### Making Easy the default

Canvas is still the default mode for new charts. To open charts in Easy mode by default, go to your **Appearance** settings and change the chart editor mode under **Workspace**.

## Building a chart

The left panel defines **what data** the chart shows. The right side controls **how it looks**.

### Series

A series is one value or line in your chart. Each series gets a letter (**A**, **B**, ...) and a title that shows its data source and measure, for example "All events · Unique servers".

- **Measure** chooses what each series calculates, such as **Total count** or **Unique servers**.
- Click **Add series** to add another one. On widgets, every series appears as its own value next to the others. On tables, every series becomes its own column. On line, area and bar charts, every series becomes its own line or bar.
- Click the filter icon on a series to add filters that apply only to that series.
- Click the trash icon to remove a series.

Series names are used as legend entries, table column headers, and widget labels.

Click **Formula** to add a series calculated from your other series.

![Two series, "Unique" and "Total", shown side by side on a widget](/images/chart-editor/easy-mode/widget-multi-series.png)

### Filters

Filters in the **Filters** section apply to every series in the chart. Click **Add filter**, pick a field, and set a value. Each active filter shows up as a chip, for example `Core Count = 4`. Click the **×** on a chip to remove that filter.

<Callout type="info">
	Use the filter icon on a series when only that series needs filtering, and the
	**Filters** section when every series does.
</Callout>

### Breakdown

**Breakdown** splits each series into groups by a field, for example one row per country or one slice per version. Leave it on **No breakdown** to show one total per series, or click the **×** next to a field to remove the breakdown.

| Setting                 | Description                                                        |
| ----------------------- | ------------------------------------------------------------------ |
| Top _n_ values          | How many groups to show, ranked by value                           |
| Group the rest as Other | Combines every group outside the top values into one "Other" group |

![Table broken down by Game Version, with one row per version and a column per series](/images/chart-editor/easy-mode/table-breakdown.png)

## Display

### Chart type and value

At the top of the preview, choose the **chart type** and use **Show** to pick how values are grouped over time:

- **Total** shows one value per series (or per group, with a breakdown) for the whole time range.
- **Auto**, **Minute**, **Hour**, **Day**, **Week**, or **Month** puts the chart on a time axis with one point per interval. **Auto** picks an interval that fits the time range.

With an interval selected, turn on **Running total** to make each point add up every point before it.

![The Show menu open with Total, Auto, Minute, Hour, Day, Week and Month](/images/chart-editor/easy-mode/easy-show-interval.png)

Widgets also compare the current value with the previous period, for example "+1.9% vs previous 24h".

### Details

| Setting     | Description                                         |
| ----------- | --------------------------------------------------- |
| Name        | Title of the chart on the dashboard                 |
| Description | Optional text shown under the name on the dashboard |

### Display options

Some chart types have extra options under **Display**. Tables, for example, have:

| Option     | Description                                                    |
| ---------- | -------------------------------------------------------------- |
| Value Bars | Shades each metric cell by its share of the column's top value |
| Totals Row | Adds a last row that sums every metric column                  |

![Table with Value Bars and Totals Row turned on](/images/chart-editor/easy-mode/table-display-options.png)

## Saving

When you have unsaved changes, **Unsaved changes** appears in the top bar. Click **Save** to save and keep editing, or **Save & close** to save and go back to the dashboard.

## How Easy mode maps to nodes

If you switch to Canvas, here is where each part of the form ends up:

| Easy mode     | Canvas nodes                                                   |
| ------------- | -------------------------------------------------------------- |
| Series        | Its own pipeline, from a **Data Source** to an **Output** node |
| Measure       | An **Aggregate** node in that series' pipeline                 |
| Series filter | A **Filter** node in that series' pipeline                     |
| Filters       | **Filter** nodes in every series' pipeline                     |
| Breakdown     | A **Group By** node                                            |
| Formula       | A **Formula** node                                             |

See [Flow Nodes](/platform/chart-editor/flow-nodes) for what each node does, and [Output & Multi-Series](/platform/chart-editor/output-nodes) for how multiple series are combined.
