The FastStats MCP server lets AI tools that support the [Model Context Protocol](https://modelcontextprotocol.io) work with your projects. They can query your analytics, triage errors, read session replays, and build dashboards.

It's a hosted server, so there's nothing to install or run. Add this URL to your client:

```txt
https://api.faststats.dev/v0/mcp
```

The server uses the Streamable HTTP transport. A client that only supports stdio can connect [through a bridge](#other-clients).

## Connect your client

Most clients sign in with OAuth, so you only need to add the URL. To connect without a browser, use an [API key](#connect-with-an-api-key) instead.

### Other clients

Point your client at `https://api.faststats.dev/v0/mcp` as a remote HTTP server.

If it supports OAuth, it finds the sign-in page and registers itself, so you don't need a client ID or secret. If it doesn't, [use an API key](#connect-with-an-api-key).

If your client only supports local stdio servers, or can't sign in, use the third-party [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) bridge. It needs Node.js and opens your browser to sign in:

```json
{
	"mcpServers": {
		"faststats": {
			"command": "npx",
			"args": ["-y", "mcp-remote", "https://api.faststats.dev/v0/mcp"]
		}
	}
}
```

## Sign in and approve access

When you connect with OAuth, your browser opens a FastStats page. Sign in if you need to, then choose what the client can reach:

- **Workspaces:** your personal projects, one or more organizations, or both. The client only sees the workspaces you pick, and it has your role in each of them.
- **Access:** **Read and write** lets the client make changes. **Read only** lets it see your data but change nothing, and it won't see any tools that make changes.

Select **Approve** to finish. The client stays connected, so you won't need to sign in each time.

To change your choices, disconnect and sign in again from your client. Your new choices need a new approval.

<Callout type="warning">
	With **Read and write** access, changes apply as soon as a tool runs. Choose
	**Read only** if you only need answers, and only approve clients you trust.
</Callout>

## Connect with an API key

API keys suit CI jobs and other setups where nobody can sign in through a browser. The key's [permissions and project access](/platform/organizations/roles#api-keys) limit what every tool can do.

1. Create a key in the **API keys** tab of your user or organization settings
2. Choose its projects and permissions. The **Read-only** preset is a good start for anything that doesn't need to make changes
3. Send the key as a bearer token with each request

<Tabs items={["Claude Code", "Codex", "Antigravity CLI", "JetBrains", "Antigravity", "Cursor", "VS Code", "Zed"]}>
	<Tab value="Claude Code">

```bash
claude mcp add --transport http faststats https://api.faststats.dev/v0/mcp \
  --header "Authorization: Bearer $FASTSTATS_API_KEY"
```

    </Tab>
    <Tab value="Codex">

```bash
codex mcp add faststats --url https://api.faststats.dev/v0/mcp \
  --bearer-token-env-var FASTSTATS_API_KEY
```

    </Tab>
    <Tab value="Antigravity CLI">

```bash
agy mcp add --header "Authorization: Bearer $FASTSTATS_API_KEY" \
  faststats https://api.faststats.dev/v0/mcp
```

    </Tab>
    <Tab value="JetBrains">

Junie, Air, and Air in your IDE all use this format. Replace `<your-key>` with your key, and keep the entry in a user-level file such as `~/.junie/mcp/mcp.json` or `~/.jetbrains/mcp/mcp.json`.

		}
	}
}

## Check the connection

Ask your client:

> List my FastStats projects.

You should see the projects you gave it access to, each with a link to the app. If you have only one project, you don't need to name it in later questions.

## What you can do

Here are a few things to try:

- "Which pages got the most traffic last week, and where did the visitors come from?"
- "What are the worst new errors since the last release? Find the cause in this codebase."
- "Find session replays where someone hit the checkout error, and tell me what they did first."
- "Build a dashboard for our signup funnel."
- "Write a notebook summarizing how this month went."

### Tools

| Area                               | Tools can                                                                           |
| ---------------------------------- | ----------------------------------------------------------------------------------- |
| Projects                           | List, describe, and create projects, and get their setup details                    |
| Data                               | Run SQL, read dashboards and insights, render charts, and detect anomalies          |
| Library                            | Create and edit dashboards, charts, funnels, Sankeys, and retentions                |
| [Errors](/platform/error-tracking) | Find, inspect, comment on, and update issues, and see trends and errors per release |
| Session replays                    | Search, read, and collect replays, and read replay insights                         |
| People                             | Look up users and their sessions, and manage segments                               |
| [Notebooks](/platform/notebooks)   | Read, create, and update notebooks                                                  |
| Feature flags                      | List and set flags                                                                  |
| Event markers                      | Record deploys and other events so charts and anomaly detection can show them       |

Tools check your role or the API key's permissions. If a project doesn't track something, or you don't have access to it, those tools report that it isn't available.

### Prompts

The server also offers ready-made workflows. Clients that support prompts usually show them as commands. In Claude Code, they look like `/mcp__faststats__triage_errors`.

| Prompt                | What it does                                                                         |
| --------------------- | ------------------------------------------------------------------------------------ |
| `setup_tracking`      | Connects this codebase to FastStats: creates or picks a project and installs the SDK |
| `triage_errors`       | Sorts new and regressed errors by impact and finds their causes in this codebase     |
| `fix_error`           | Investigates one error issue, finds the root cause, and fixes it                     |
| `record_deploy`       | Adds a deploy marker for what you just shipped                                       |
| `weekly_report`       | Writes a notebook summarizing a period, with live charts                             |
| `investigate_anomaly` | Finds out why a metric moved: what changed, when, and for which users                |
| `build_dashboard`     | Designs a dashboard for a goal, checks it with a dry run, then creates it            |

### Resources

Clients that support resources can attach project context to a conversation, using URIs like `faststats://<project>/overview`. In Claude Code, `@`-mention them. They include the project overview, SQL tables, topic guides, notebooks, dashboard data, and error issues.

## Troubleshooting

### The client says it needs authentication or returns 401

Finish signing in from your client, such as `/mcp` in Claude Code. If you use an API key, check that it hasn't expired or been revoked, and that you send it as `Authorization: Bearer <key>`.

### The client can't finish signing in

Connect with an [API key](#connect-with-an-api-key) or the [`mcp-remote` bridge](#other-clients) instead.

### A tool needs the `mcp:write` scope

You approved **Read only** access. Disconnect, sign in again from your client, and choose **Read and write**.

### A project is missing

The connection doesn't include that project's workspace, or the API key doesn't include that project. Sign in again and pick the workspace, or update the key's projects.

### A tool says something isn't available

Your role or the API key doesn't have the permission it needs, or the project doesn't track that data.

### A result was cut off

Results are limited to 100,000 characters. Ask for less, such as fewer columns, a shorter period, or a specific item.
