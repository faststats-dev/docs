Use `dev.faststats.sponge.FastStatsSponge` for Sponge plugins. Requires Java 17+.

**Artifact:** `dev.faststats.metrics:sponge`

If you absolutely cannot use Java 17, a Java 8 fallback is available as
`dev.faststats.metrics.j8:sponge` with the same version number. Prefer the
standard artifact above for new projects.

```java
import com.google.inject.Inject;
import dev.faststats.ErrorTracker;
import dev.faststats.FastStatsContext;
import dev.faststats.Metrics;
import dev.faststats.sponge.FastStatsSponge;
import org.jspecify.annotations.Nullable;
import org.spongepowered.api.Server;
import org.spongepowered.api.event.Listener;
import org.spongepowered.api.event.lifecycle.StartedEngineEvent;
import org.spongepowered.api.event.lifecycle.StoppingEngineEvent;
import org.spongepowered.plugin.builtin.jvm.Plugin;

@Plugin("example")
public class ExamplePlugin {
    public static final ErrorTracker ERROR_TRACKER = ErrorTracker.contextAware();
    private @Inject FastStatsSponge fastStats;

    private @Nullable FastStatsContext context = null;

    @Listener
    public void onServerStart(final StartedEngineEvent<Server> event) {
        this.context = fastStats.builder()
            .token("YOUR_TOKEN")
            .errorTrackerService(ERROR_TRACKER)
            .metrics(Metrics.Factory::create)
            .build();
        context.ready();
    }

    @Listener
    public void onServerStop(final StoppingEngineEvent<Server> event) {
        if (context != null) context.shutdown();
    }
}
```

Without dependency injection, use the static
`FastStatsSponge.builder(plugin, configDirectory)` instead.

See [Error Tracking](/java/error-tracking) for configuring error reporting.

Replace `YOUR_TOKEN` with your project token. To keep it out of your git
repository, [inject it at build time](/java/build-time-token) instead of
hardcoding it.
