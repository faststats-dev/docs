Use `dev.faststats.bukkit.FastStatsBukkit` for Bukkit-based server plugins. Requires Java 17+.

**Artifact:** `dev.faststats.metrics:bukkit`

If you absolutely cannot use Java 17, a Java 8 fallback is available as
`dev.faststats.metrics.j8:bukkit` with the same version number. Prefer the
standard artifact above for new projects.

```java
import dev.faststats.ErrorTracker;
import dev.faststats.FastStatsContext;
import dev.faststats.Metrics;
import dev.faststats.bukkit.FastStatsBukkit;
import org.bukkit.plugin.java.JavaPlugin;

public final class ExamplePlugin extends JavaPlugin {
    public static final ErrorTracker ERROR_TRACKER = ErrorTracker.contextAware();

    private final FastStatsContext context = FastStatsBukkit.builder(this)
        .token("YOUR_TOKEN")
        .errorTrackerService(ERROR_TRACKER)
        .metrics(Metrics.Factory::create)
        .build();

    @Override
    public void onEnable() {
        context.ready();
    }

    @Override
    public void onDisable() {
        context.shutdown();
    }
}
```

Call `context.ready()` once, in or after `onEnable()`, before using metrics or error tracking. Calling it earlier, for example from the constructor or `onLoad()`, logs an error and leaves the context not ready. On Paper-based servers, this also registers additional exception handlers. See [Error Tracking](/java/error-tracking) for configuring error reporting.

Replace `YOUR_TOKEN` with your project token. To keep it out of your git
repository, [inject it at build time](/java/build-time-token) instead of
hardcoding it.
